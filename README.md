# PESO Beauty Web

Public website and client-facing digital experience for PESO Beauty Bar, operated by PESO Beauty, LLC, within The Kousins Corporation operating enterprise.

## Development Model

- `main` — production-ready releases
- `dev` — stable development integration
- `feature/*` — implementation work
- Pull requests are required for feature integration and production promotion.

## Initial Stack

- Next.js
- TypeScript
- App Router
- Tailwind CSS
- ESLint

## Brand Baseline

- Primary service brand: PESO Beauty Bar
- Legal operating entity: PESO Beauty, LLC
- Parent: The Kousins Corporation
- Current tagline: **CONFIDENCE, BEAUTY, SUCCESS.**

Foundation implementation begins with `PESO-WEB-001`.
